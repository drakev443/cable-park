# Cable Park

A side-view wakeboarding game in a single `index.html` — no frameworks, no build step.
The cable pulls you across the lake; hit the kickers, throw tricks, and land clean to build your combo.

## Play

Open `index.html` in a browser (or serve the folder with any static server).

| Key | Action |
|---|---|
| ↓ / S (hold on approach) | Pump — load the edge for more pop off the kicker |
| ← / A (in air) | Backroll |
| → / D (in air) | Frontroll |
| ↑ / W (in air) | Spin |
| Space (in air) | Grab — let go before you land! |
| P / Esc | Pause |
| M | Mute |
| R | Restart run |

On phones and tablets, on-screen buttons appear automatically (landscape works best).

## Scoring

- Flip: 500 per full rotation · Spin: 150 per 180° · Grab: 100 per ¼ s held · plus air time.
- Points are multiplied by your combo (×1 → ×10). Each clean trick raises it.
- Landing slightly off-level is "sketchy" (half points). Landing badly, sideways, or still grabbing is a wipeout and resets the combo.
- Best score is saved in your browser.
